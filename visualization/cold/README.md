# Холодный проход: 206,002 CFM

Расход вентилятора — **206,002 CFM**, без нагрева. Рассчитано 30 итераций
`simpleFoam`, RANS kOmegaSST, текущая геометрия мангала 850 × 400 × 160 мм,
задний зазор 100 мм, слева без зазора. Вентилятор задан на конце трубы Ø200.

**Это предварительное поле: строгая сходимость SIMPLE ещё не достигнута.**
Тепловой факел, дым и захват дыма в этом проходе не рассчитывались.
Максимальная скорость по всему объёму — 3,517 м/с. Последняя нормированная
глобальная ошибка непрерывности OpenFOAM — −5,37e−9; это не отдельное
доказательство нелинейной сходимости.

## Blender, офлайн

Импортируйте `cold-flow.obj` через File → Import → Wavefront OBJ.
Файл `cold-flow.mtl` должен лежать рядом. Размеры — метры, масштаб 1,
вертикаль Z (при необходимости Forward=Y, Up=Z).

В сборке мангал, зонт и 36 отдельных линий тока. Трубки радиусом 2 мм —
условная визуализация вычисленных траекторий, не дополнительные детали
конструкции. Стрелки показывают направление интегрирования вперёд.
Линии начинаются перед входом и над чашей.

Цвет трубок: синий — низкая скорость, красный — 0,6 м/с и выше.
Шкала насыщается на 0,6 м/с, чтобы были видны различия во входной зоне;
полный максимум 3,517 м/с. В Material Preview видны цвета. При необходимости
скройте объект `Hood` в Outliner, чтобы рассмотреть поток внутри.

## Браузер

Откройте `cold-flow.html`. Данные встроены в файл; для загрузки библиотеки
VTK.js с CDN нужен интернет. Файл не требует локального HTTP-сервера.
Кнопки меняют ракурс, флажки включают сечения, ползунки задают прозрачность
стенок и диапазон цветовой шкалы. Отрисовка в браузере здесь не проверялась;
проверены структура данных, индексы и синтаксис JavaScript.

## ParaView, офлайн

Компактный набор: `cold-view.vtm`. Он ссылается на соседние каталоги
`geometry`, `sections` и `streamlines`; сохраняйте их вместе.

1. File → Open → `cold-view.vtm`, затем Apply.
2. Для раскраски выберите поле `U`, компонент `Magnitude`.
3. При необходимости скройте боковое/горизонтальное сечения через Block Inspector.
4. Можно открыть отдельный файл `sections/frontSection.vtp` и линии
   `streamlines/intakeStreamlines.vtp` / `grillStreamlines.vtp`.

Полная сетка с U и p: `VTK/isothermal_30.vtm` (около 339 МБ со всеми файлами).
В ней есть `internal` и `boundary`. Для собственного сечения выберите
внутренний блок и примените Slice. Поле p в холодном `simpleFoam` —
**кинематическое давление**, единицы м²/с².

VTK выгружен штатными `foamToVTK`, `surfaces`, `streamLine` OpenFOAM v2606.
Привязка ParaView к OpenFOAM-reader не требуется.
Веб-интерфейс использует [VTK.js](https://kitware.github.io/vtk-js/docs/).

## Повторить

Из корня проекта:

```bash
./mangal run --cold --iterations 30
./mangal visualize --cold
```

`mangal visualize` пересоздаёт сечения, линии тока, полную VTK-выгрузку, HTML и OBJ
из последнего сохранённого холодного поля. Номера итераций SIMPLE не являются
физическим временем. Холодный расчёт и его логи находятся в
`validation/isothermal/`. Тепловой решатель остаётся отдельным незавершённым
этапом: его неудачные проходы не использованы в этой визуализации.
